# resume-structure

Formatting and structure rules for resumes. It controls layout, section order, dates, bullet counts, ATS-safe files, and keyword matching. The content always comes from the user.

## What it does

- Applies a consistent page layout and section order
- Scales bullet counts to tenure and leads with metrics
- Produces an ATS-safe .docx plus a .pdf for direct sends
- Checks keyword coverage against a job description
- Runs a quality checklist before delivering

## What it won't do

- Invent or change employers, titles, dates, or metrics
- Add skills the user does not have

## Files

- `SKILL.md`: the skill
- `evals/evals.json`: sample test prompts
