# linkedin-content-engine

A LinkedIn workflow that researches a topic, offers hooks from different frameworks, drafts the post in the user's own voice, and runs an AI-tells cleanup pass.

## What it does

- Asks once for goal, audience, writing samples, and proof points
- Researches a fresh data point before drafting
- Offers three hooks from different frameworks (hot take, data + story, contrarian, career moment, build in public)
- Drafts a 150-300 word post and removes common AI-writing tells
- Optionally saves the approved post to a content calendar

## What it won't do

- Invent metrics, quotes, clients, or outcomes
- Name real people without the user's permission

## Files

- `SKILL.md`: the skill
- `evals/evals.json`: sample test prompts
